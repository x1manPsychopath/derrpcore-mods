DerrpCore mod checklist

The server runs 19 mods, and your game has to load the same ones or joining fails with “game version mismatch”. Work down this page once and you're set.

  1. Subscribe to the 17 Steam Workshop mods.
  2. Start Core Keeper and subscribe to the 2 mod.io mods from the main menu's Mods button.
  3. Check that the mods in “Keep these off” are off, then restart the game.
  4. Install the required fix below (one download), then restart the game.
  5. Ask NeoDerrp for the join code and paste all of it into Join Game.

Required fix 1

  • Download

    CoreLib gives the Root Workbench a random ID every launch, so crafting it refunds and a few modded items get mixed up. The fix makes the ID the same for everyone.

    1. Close Core Keeper.
    2. Download the zip and unzip it anywhere.
    3. Double-click Install-CoreLibFix.bat (if Windows warns you: More info, then Run anyway).
    4. Check it says FIXED or already fixed, then start the game.
    5. Run it again whenever CoreLib updates on Steam.

If joining fails

“Game version mismatch”

A required mod is missing, turned off, or on a different version. Restart Core Keeper after subscribing; mods only load when the game starts.

“Game server not found”

The code got cut off. Paste the whole join code; it's 15 characters.

Still stuck

Send NeoDerrp your Player.log. It lists every mod your game loaded, and the server manager compares it for you. Paste this into File Explorer's address bar to find it:

%USERPROFILE%\AppData\LocalLow\Pugstorm\Core Keeper\Player.log
Mod list as of October 18, 2026. If NeoDerrp adds or updates mods, you'll get a new link.
